
# Mapa de Objetivos

## 1. Introdução

O Mapa de Objetivos tem como finalidade representar visualmente os principais objetivos que cada persona deseja alcançar ao interagir com o sistema de gerenciamento de materiais do Laboratório de Biologia da UFAM.

Os mapas foram elaborados com base nas necessidades identificadas durante a etapa de imersão e na metamensagem do sistema.

Nesta etapa, são apresentados apenas os objetivos dos usuários, sem detalhar operações ou planos de execução, os quais serão abordados posteriormente nos HTAs.

## 4. Considerações finais

Os mapas de objetivos representam as principais necessidades e expectativas das personas em relação ao sistema.

A partir deles, é possível compreender os diferentes objetivos dos professores e técnicos de laboratório, considerando suas responsabilidades e necessidades específicas.

Esses mapas servirão como base para a próxima etapa do projeto, a elaboração dos HTAs (Hierarchical Task Analysis).
